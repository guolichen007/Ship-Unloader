# V1.5 R1 S4 R2G 船舱矩形内沿精修与 map 验证

## 范围与判定

R2G 只精修 R2F 已有矩形，不增加开口候选。船轴由已有 `structural_axes()` 给出，R2G 先诊断；仅当 RawXYZ 跃迁与逐节点归一化的 Raw3D 边方向共同证明漂移时才改变全船共享轴。四边仍为同一组正交轴上的直线，角点由交点计算。目标是船舱开口内沿；船体外轮廓、货物、码头、横梁表面和驾驶室不得当成四条船舱钢边。

侧边定位保留栅格去重前的候选以及连续 RawXYZ/Raw3D 观测。沿边中段划分互不重叠窗口，分别测量 rho，再用中位数和 MAD 审查离群截面。大位移若没有相对原边的实际证据增益，或沿边一致性不足，则保留 R2F 原边并标 `REFINEMENT_NOT_CONFIDENT_KEEP_R2F_SIDE`。栅格独立重复的真实高度跃迁可支持无 3D 锚的亚栅格修正；单点噪声不能升级为 `INNER_EDGE`。最终联合四边排序不奖励面积。

同船等宽只在当前扫描至少两个矩形的两条横向边均有强 Raw3D 与栅格支持，且宽度 MAD 足够小时形成 `CURRENT_SHIP_WIDTH_CONSENSUS`。这个值只给弱边组合做最后的平分裁决，不移动强边，不跨场景共享，不凭宽度构造没有观测的边。08-01 当前没有两个足够强的宽度参考，因此目标宽度为 `null`，H001 V0 保留原边；不把实船等宽事实硬编码成固定米数。

## 回归与剩余限制

新增测试覆盖轴漂移、距离小于栅格去重宽度的内外沿、亚栅格、面积偏置、局部噪声强峰、弱边同船宽度平分及跨场景隔离；旧测试继续覆盖货物、溢出、旋转、外船体、驾驶室、多舱与缺角。另测 ASCII PLY 验证输入和零矩形状态。R1 Python 99 项通过，相关 CTest 10 项通过，V1.4 frozen 校验 72 个文件通过。`baseline_004` 的代码与配置未修改，六景运行核对了它的输入 SHA 和拓扑一致性。

完整 CTest 的首次 `g5` 失败原因是旧构建内嵌 SHA 与当前 Git HEAD 不一致。按当前 HEAD 重新配置 CMake 并构建后，定向 `g5` 通过。V1.4 源码未改，故该失败不是本轮船舱算法回归。

剩余问题是弱边绝对定位以及额外样本的上游漏检和碎片误候选。它们应先通过独立人工内沿标注区分，再做下一轮开发；本轮没有可支持“精准标定已在全部船型通过”的证据。
