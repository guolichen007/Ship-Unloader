# R2H-B5-R1 逐边仲裁与验证集复核

## 目标与边界

基线 `9a7b2e4eb095bb02c8e4fd43f2dc6f513308c4ab`。本轮只改静态 review 求解与可视化，不改 V1.4、正式 acceptance gate、目标船选择或时序累积。原始 PCD/PLY 的 SHA 必须与 B2 报告一致；PNG 和人工预期不进入 detector。输出框仍是审查候选，没有独立 opening inner-edge Golden，不能宣布厘米级钢内沿标定通过。

## 开发集修复

原 B5 在角点不足时整框沿用 B4。8-22 H000 U1 的 B4 位置为 22.424 m，R2G 为 24.337 m。B4 候选混合了 V0000/V0001/V0002 支持，且沿开口端方向的高差只有约 0.189 m；R2G 附近 24.342 m 有本船 Raw3D 与 BEV 支持，高差约 2.432 m，外侧还有另一开口的间隙关系。统一逐边规则因此恢复 R2G 的 24.337 m，并记录 `B4_MIXED_CONTEXT_WEAKER_OPENING_END`。其余两舱和 H000 其他边维持原有位置。相同规则对 4-16 的单舱端边不回退，保留 B4 右端内收 49.601 m；防止把高差强的船外端缘误判为开口端缘。

08-08 将 V0/V1 两条长边各分成五个有占据支持的 U 截面。V0 局部 rho 为 `[4.53, 4.53, 4.53, 4.53, 4.53]` m；V1 为 `[14.39, 14.29, 14.29, 14.39, 14.39]` m。两者的截面中位数为 4.53/14.39 m，MAD 均为 0，表示**离散候选模式一致**，不是物理测量误差为零。V0 的 4.89 m 候选只在 3/5 截面呈单侧开口转折，不能凭局部 Raw3D 强线赢过 4.53 m。最终位置仍是 4.53/14.39 m、`PARTIAL_HATCH_3C`，左下角仍为几何推定。V1 的截面选择更多依赖持久高度族和结构线，不能称为五段独立钢边实测。

Normal6 最终候选数保持 `08-01/08-08/4-16/6-8/7-16/8-22 = 2/1/1/1/1/3`。08-01 共用隔板与不等长两舱保持；6-8、7-16 的多模式弱边保持 `UNRESOLVED`，没有为了补全矩形再次过裁剪。

## 无 B4 输入的验证集

增加 B1 船体、B2 三强边 PARTIAL proposal、Raw XYZ 高度/角点的保守启动路径。重叠 proposal 先归组；若中部出现 Raw XYZ 密度脊，并可分别吸附到本船 Raw3D+BEV 的两条横梁结构面，分别尝试 opening cell。4-22 的两面约为 −19.34/−17.69 m，产生两个独立的 `PARTIAL_HATCH_3C` 供审查候选；各自的缺角明确标记为几何推定，两个候选均不再重复占用同一个 B2 HatchHypothesis。右舱还使用多个局部高度 level 持续存在的 footprint context corner，不能称为三个钢角实测。若横向结构只是宽带，或拆出的 cell 缺少可追踪的角点组合，仍保留未决。该路径尚未完全解决复合 B2 proposal 的召回问题。

## 分色图的含义

`Ship-Unloader-Work/review/r2h_b5_r1/<scene>/E_semantic_regions.png` 和 `r2h_b5_r1_holdout/<scene>/E_semantic_regions.png` 按点来源与候选几何渲染：紫色为当前船体之外/未归属点，蓝色为船体中开口候选之外，绿色为候选框内的实测点，琥珀色为候选边界，灰色虚线为未决 seed，白色为无返回。**颜色只描述空间关系，不是 Cargo/Deck/Steel 语义真值；琥珀线不代表已确认钢围挡。** 图中也标出 PARTIAL/UNRESOLVED 状态。`F_section_rho_modes.png` 展示多截面候选，`G_stage_arbitration.png` 同画 R2G/B4/最终逐边位置。所有审查 PNG/JSON 在忽略的 Work 目录，不提交点云或派生图。

按用户指定，另在 `Ship-Unloader-Work/review/船舱静态标定效果展示/<场景>/` 输出独立的 `原始XYZ高度_船舱候选单图.png`、`点云分区_舱内围挡船外.png`、`点云分区_采样彩色.ply`、`标定结果与证据.json`。已生成 08-01、08-08、4-16 三张原始 XYZ 单图，并额外生成 4-22 验证集局部候选与其他 Normal6 的同格式图。图题、图例、数据字段使用中文；彩色 PLY 是有上限的点采样，坐标仍为原始 XYZ。人工审图显示 08-01 两舱与横梁分隔保留、08-08 长边沿可见开口内沿、4-16 右端仍内收；4-22 两候选分别落在横梁两侧。4-16 等 `UNRESOLVED` 框采用虚线，视觉效果不改变验收状态。

## 验证结论

Python 全量 245 项通过，其中五项旧 B5 红测试仍为预期失败；V1.4 冻结校验 72/72；B5 角点、逐边仲裁和 V1.4 冻结 CTest 3/3。Normal6 原有计数与 4-16 内收未退化，8-22 H000 U1 恢复了有独立较强证据的旧边。新增反证覆盖持久高度 context corner 只能形成 `PARTIAL` 和展示分区不冒充钢材分类。静态真实内沿状态仍为 `UNVERIFIED_NO_INDEPENDENT_INNER_EDGE_GOLDEN`。验证集目前以 `PARTIAL/UNRESOLVED` 复核为主，不能报告为静态标定 PASS。
