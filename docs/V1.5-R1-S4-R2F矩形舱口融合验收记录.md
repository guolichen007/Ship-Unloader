# V1.5 R1 S4 R2F 矩形舱口融合验收记录

## 目标与输入边界

本轮只输出船舱开口围挡的矩形内沿候选。船体外轮廓、码头、货物表面与船尾驾驶室不作为舱口。横梁可以把同一条船上的相邻开口分开；求解器不预设舱口数量、长度或宽度。

算法输入为 `v15_dataset_manifest.json` 中 `DEVELOPMENT` 六景的原始 PCD XYZ、R1 Height 区域层级和从原始 XYZ 重新计算的 S4R1 三维线段。`r1_structural_lines` PLY 只用作复核图底图。PNG、PLY、人工注释和 GT 均不作为求解输入。每景在读取前核对 PCD SHA 与 Height baseline_004 的输入 SHA。

R0 历史分支与 `r0_a` 作只读溯源审查；`r0_a` 的 blind index 为 `STRICT_RAW_XYZ_ONLY`，没有复用历史模型、标注或拟合参数。V14 frozen paths 及 baseline_004 均未修改。

## 方法

1. 按 S4R1 结构方向将原始 XYZ 投到船轴坐标，生成 coarse/fine 的中位高度、点数、垂直跨度与有效掩码。高度、密度和垂直跨度跃迁分别保留真实采样位置；栅格图像不进入算法。
2. 三维 profile break / face 与原始栅格线段分别形成候选轴线。每条候选矩形边记录两类证据覆盖率、观测区间、原始观测 ID、高度内外关系及是否为 canonical inner edge 候选。
3. 在 Height 层级区域内搜索四边组合。至少三边需观测支持、至少一边需三维结构支持，最多一边可由几何约束补全。禁用 `INTERIOR_SURFACE` 与 `ROLE_AMBIGUOUS_OVERFLOW` 作为钢边确认来源。
4. 内部横梁若有持续三维结构线，或有原始栅格线并得到局部三维面/跨越高度的独立支持，则禁止跨梁合并。单纯密度条纹及货物隆起不能充当横梁。
5. 相邻的内外平行沿在矩形拓扑相同的条件下，比较内外高度跃迁，优先保留更强的开口沿。升高的完整矩形若与另一个已测开口相邻，只保留为角色待核片段，不能直接赋予舱口编号；其几何与拒绝理由仍在 JSON 中。

四角由边线交点给出，分别标为 `GEOMETRIC_LINE_INTERSECTION`；这不是独立观测角点。所有输出均在原始点云坐标系中。模型 PLY 标记为 `PROVISIONAL_RECTANGLE_MODEL_NOT_RAW_STEEL`。

## 六景复核

运行命令：

```powershell
python -m ship_perception.r1_static.rectangle_fusion_review --scene-set normal6 --recompute-structural --output-root Ship-Unloader-Work/review/r2f_rectangular_fusion_final
```

## 验证与剩余限制

合成测试覆盖缺角、缺三维端边、内外平行沿、货物隆起、密度条纹、局部横梁、同 ROI 的二/三舱、船体与驾驶室混淆、禁止角色及旋转坐标系。六景候选只是离线审查产物。尚无独立双人裁决的真实内沿 golden，故 `static_calibration_status=UNVERIFIED_NO_INDEPENDENT_INNER_EDGE_GOLDEN`；不得宣称真实误差达标或把此结果提升为 runtime steel boundary。

V1.5 quick gate 在本轮仍失败：synthetic 通过，real_smoke 和 integration 失败。2026-09-23 与本轮前 2026-09-28 的同一 gate 报告也为相同三项状态，本轮没有修改该 gate 或降低阈值。此失败与 R2F 离线审查结论分别记录。
