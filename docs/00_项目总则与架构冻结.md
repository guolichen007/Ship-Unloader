# 项目总则与架构冻结

> 状态：FROZEN
> 适用版本：V1.5-R / V1.5-T
> 最后更新：2026-09-22
> Owner：Ship-Unloader Engineering
> 性质：Architecture Freeze
> 变更规则：未经明确评审，不得由 Codex / ClaudeCLI / 开发者自行更改。

## 1. 唯一业务目标

当前只解决一件事：

> **对当前作业目标船，在真实点云中稳定、可解释地识别视野内 1～3 个船舱，并得到可靠的 opening-side 结构边界。**

优先级：

```text
船舱识别
  >
结构边界精度
  >
部分遮挡
  >
整船刚体跟随
  >
控制 / PLC / 抓取 / Web
```

以下内容当前全部 OUT OF SCOPE：

- PLC；
- 抓取规划；
- Control Prior；
- Web；
- RTK / GNSS；
- 新 ES-EKF；
- 新大型语义网络；
- PTv3；
- 8 类全点云语义分割；
- 自动作业船选择。

## 2. 冻结的 Production Pipeline

```text
Strict Decode
→ Target Vessel Seed / ROI
→ Geometry Proposal
→ Optional Legacy CNN Proposal
→ Candidate Union
→ H=1 / H=2 / H=3 Joint Hypothesis
→ Per-Hatch Local Deck
→ opening-side 3D Boundary Evidence
→ Boundary Fusion
→ Hatch Polygon / PARTIAL / UNRESOLVED
→ Fixed Ship Frame B
```

### 不再作为 Production 主链的能力

```text
Global Deck
Global Structural ROI
全图单一低洼连通域解释
绝对 Y 最小作为物理真值
固定窗口长度作为物理真值
CNN 矩形直接作为最终钢边
```

这些能力可以保留在 Research / Legacy 路径，但不得反向阻塞 Production。

## 3. 输入契约

产品运行时允许的输入：

```text
Raw XYZ
Target Vessel Seed /可信作业范围
LiDAR extrinsics
必要的平台/传感器位姿
```

**评分标注中的 Hatch ROI 不属于产品输入。**

如果运行时没有可信目标船 seed，系统必须返回：

```text
TARGET_VESSEL_UNRESOLVED
```

不得偷偷使用人工 GT、最小 Y 或 sealed label 代替。

## 4. 输出契约

每个 Hatch 至少包含：

```text
hatch_id
polygon_in_ship_frame
observation_status
edges[]
confidence / ambiguity
reason
```

每条边至少包含：

```text
edge_id
visibility
evidence_type
opening_side_status
observed_support
uncertainty
reason
```

允许失败输出：

```text
NO_CONFIRMED_HATCH
HATCH_COUNT_AMBIGUOUS
TARGET_VESSEL_UNRESOLVED
LOCAL_DECK_UNRESOLVED
INSUFFICIENT_OBSERVATION
POSE_INVALID
OUT_OF_SCOPE
```

## 5. Evidence Freeze

允许的 evidence：

```text
OBSERVED_PROFILE_BREAK
OBSERVED_3D_FACE
OBSERVED_BEV_CONTOUR
INFERRED_GEOMETRY
INFERRED_VESSEL_PRIOR
HISTORICAL_MODEL
OPERATOR_CONFIRMED
UNKNOWN
```

规则：

- `OBSERVED_*` 必须存在原始测量支持；
- `INFERRED_*` 不得改名成 `OBSERVED_*`；
- `HISTORICAL_MODEL` 必须带来源和年龄；
- 静态 XYZ 缺点默认 `UNKNOWN`，不能凭空写成 `OCCLUDED`；
- `OBSERVED_BEV_CONTOUR` 只能辅助，不得单独承担最终 opening-side 钢边真值。

## 6. 坐标系冻结

所有舱口统一属于固定 Ship Frame `B`：

```text
P_hatch^W(t) = T_W_B(t) · P_hatch^B
```

变换记号：

```text
T_A_B = 将 B 坐标表达转换到 A
```

实现：

```text
Eigen::Isometry3d
```

规则：

- 船体位姿用 `double`；
- 点云存储可用 `float`；
- 不允许混用 `T_AB / TBA / pose_ab` 等模糊命名；
- 不允许每个 Hatch 单独估计世界漂移。

## 7. 版本顺序冻结

```text

完全覆盖 / Historical / Prior-only
```

禁止跨阶段“顺手”实现后续功能。

## 8. 架构变更流程

任何下列变化必须先提交 ADR / Architecture Review：

- Production Pipeline 改序；
- 增删核心模块；
- 改 Evidence 类型；
- 改坐标树；
- 改数据 split；
- 改核心 acceptance gate；
- 引入深度学习主干替代几何主干；
- 允许 Global Deck 回归 Production；
- 更改 V1.4 frozen source。

未完成评审前，代码不得先行。
