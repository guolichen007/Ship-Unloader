# 船舱识别算法原理

## 输入

接收包含 `x/y/z` 的PCD（ASCII、binary、binary_compressed），保存原始坐标系、输入摘要和点索引。强度字段不作为识别的必要条件。

## 几何识别

1. **结构与归属**：场景高度/密度和局部三维结构提取船体候选。多船场景缺乏可靠泊位参考时明确返回未决，不推测目标船。
2. **多源召回**：结合高度图、BEV、Raw3D、结构线族和S4提名开口区域，不将高度图局部碎片直接记为新舱。
3. **开口拓扑**：依据内部成员、实际隔板和独立开口结构确定OpeningCell，避免同一个舱口变成两个框或跨舱大框。
4. **Raw逐边复核**：在独立物理断面中比较甲板、近竖直面、高度转折与内外空间；识别船侧/岸水污染风险。同船宽度相似性仅辅助排序，不能替代钢边测量。
5. **矩形与尺寸**：用U0/U1/V0/V1四边联合求解矩形；保留严格几何与二维复核建议两种输出。长度和宽度基于实际四边，不使用世界XY轴对齐包围盒。
6. **XYZ结果**：输出四角原始XY，独立测量Z；未观测高度为 `null`，不以零或甲板假定高度填充。

## 证据等级

开口身份、严格矩形可解、二维复核建议、钢边测量及设备控制资格分别记录。部分场景存在相互竞争的平行边或缺少外侧平台见证，这类候选不能因软件输出一个矩形而升级为认证钢边。

实现入口：`ship_perception/perception/`；离线一键入口：`tools/r3h_oneclick.py`。运行时不读取人工粗框答案、场景名称或预期舱数进行调参。
