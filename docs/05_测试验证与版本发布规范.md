# 测试、验证与版本发布规范

## 1. 测试金字塔

```text
Static / Format
      ↓
Unit
      ↓
Contract
      ↓
Synthetic
      ↓
Development Real Data
      ↓
Independent Golden
      ↓
Never-Seen Sequence / Site
```

低层通过不能替代高层验证。

## 2. 必备 Gate

每次代码修改至少：

```text
git diff --check
format
unit
contract
build
```

识别模块：

```text
proposal regression
oracle local geometry regression
negative cases
```

涉及 V1.4：

```text
V1_4_FROZEN=PASS
```

## 3. R0 Acceptance

必须分别报告：

```text
PROPOSAL_RECALL_PRE_NMS
PROPOSAL_RECALL_POST_NMS
GEOMETRY_PROPOSAL_RECALL
CNN_PROPOSAL_RECALL
UNION_PROPOSAL_RECALL
```

不得只报平均分。

Oracle：

```text
LOCAL_DECK_SUCCESS
BOUNDARY_SUCCESS
TOPOLOGY_SUCCESS
INSUFFICIENT_OBSERVATION
```

决策：

```text
oracle fail
→ local geometry blocker

oracle pass + product fail
→ proposal/hypothesis blocker
```

## 4. R1 Acceptance

6 个正常单船 Development：

```text
Hatch count 全正确
9 / 9 instance recall
08-01 不合并
8-22 不合并
4-16 不 false split
无 duplicate final hatch
```

特殊：

```text
8-17 不冒充整船总舱数
5-29 不跨船合并
7-2 不跨船合并
```

负例：

```text
Wharf
Cargo
Crane structure
unknown blank
```

不得升级成 confirmed Hatch。

## 5. Boundary Accuracy

旧 weak rectangle：

```text
不能作为 15cm / 20cm 精度门
```

厘米级边界精度只能来自：

```text
NEW_GOLDEN
physical opening-side definition
independent review
```

报告：

```text
edge error p50
edge error p95
corner error
support ratio
failure count
```

平均值不能掩盖失败。

## 6. R2 Acceptance

重点验证：

- 一边被料覆盖；
- 多边被料覆盖；
- 中间隔板被料覆盖；
- Cargo 高于围板。

必须证明：

```text
不把 Cargo 轮廓写成钢边
不因隔板暂时不可见强行合舱
历史边和当前 observed 分离
```

## 7. T1 Acceptance

同一船时间序列：

- sway；
- surge；
- heave；
- roll；
- pitch；
- yaw。

全部 Hatch 必须共享 `T_W_B(t)`。

验证：

```text
relative hatch geometry rigidity
world pose error
invalid pose handling
model pollution
recovery
```

## 8. Fail Evidence

任何 FAIL 必须保留：

```text
input id
commit SHA
config SHA
command
stdout/stderr
machine/env
artifact path
root-cause status
```

根因分：

```text
CONFIRMED
LIKELY
OPEN
```

禁止只写“偶现”。

## 9. Release Gate

只有全部满足才可进入 release/tag：

```text
worktree clean
required checks pass
frozen gate pass
acceptance report archived
known limitations written
rollback point known
no raw data tracked
no secret tracked
```

## 10. Release Notes

至少：

```text
Version
Commit SHA
Base SHA
Environment
Scope
Major Changes
Validation
Regression
Known Limitations
Data Contract
Migration
Rollback
```
