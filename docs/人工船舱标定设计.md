# MHR-R1 人工船舱标定设计与预登记

基线 6af9d75965994eaf4413cdb6120cfc5acf4693c5。实验路径为独立本地服务。一份输入 PCD 对应一个进程会话和一份地图构建，原始识别入口和冻结代码不参与计算。历史参考由离线验证器生成圈选扰动和二维对照，运行时只接收操作员矩形和原始点云，自动叠加仅用于当前帧身份与显示。

## 源码边界

| 接口 | 核对及使用方式 |
| --- | --- |
| `read_pcd(path, frame_id, max_points)`、`PointCloudFrame` | 只读复用；输入文件哈希和解码后 XYZ/强度语义哈希分列。帧时间为解码器记录值，PCD 默认零，非现场采集时钟。坐标原类型保留，计算转换为 float64。 |
| `R1HeightGrid.from_points(points, cell_m, origin_xy=...)` | 只读复用，先用 float64 估算尺寸和峰值。数组行 0 为低 Y；生成纯图层时翻转一次。 |
| `RawSpatialIndex.query_indexes(box)` | 只读复用查询逻辑，一次建索引。闭区间轴对齐检索返回传入数组位置；断面为本实验定义的半开区间。 |
| `output._render_scene(...)` | 旧图有抽样、色条和裁切；不作为坐标底图。 |
| `ReviewFrame.to_review(xy)` / `to_input(uv)` | 正交、无平移，可存在反射；新地图直接表达输入 XY。 |
| `LocalRimEvidence(measurement,config)` / `heldout_side(points,indexes,core,member,side,polygon,envelope,config)` | 需要真实船成员、区域和边界上下文；独立入口不构造伪角色。 |
| `ConstrainedRectangleSolver.solve(region,sides,bridge=None)` / `ReviewCornerHeight.measure_for_review(result,plane_sources=...)` | 依赖旧区域保守边界、侧证据和船物理上下文，新局部输入采用独立测量门。 |
| `select_operator_vessel(frame,context,path)`、`SelectedVesselRawContext.build(frame,scene,selection,config)`、`opening_cells(regions,bridge,local_evidence,cell_m)` | 旧选船、成员和隔板归属不由显示用叠加文件替代。 |
| `write_review_layers(payload,directory)`、`review_pipeline.run_perception(...)`、`RecallSnapshot(path,identity)`、`tools/r3h_oneclick.py` | 旧结果生成、快照、默认入口及私有运行目录保持独立。 |

## 坐标、请求和证据

`manual_map.1` 的图层字节用 SHA-256 固定，透明像素代表空格。清单哈希由排除摘要字段的排序紧凑 UTF-8 JSON 计算。像素为连续边界坐标，米制转换为 x=x0+u*s、y=y0+(ny-v)*s。默认格 0.1 m，维度最多 16384、格数 1000 万且预算 700 MB。拒绝绝对值超过 10⁷ m 的 XY，在上限附近双精度的单次舍入约 2 nm；浮点运算精度与来源 float32 的实际采样精度分别处理。坐标回环门为 10⁻⁸ m，提交双端交叉检查容差独立为 2×10⁻⁷ m。CSS 缩放、平移和留白只影响视图变换，DPR 只改变 Canvas backing store。

`manual_selection.1` 绑定会话、实例、视图、地图摘要、双输入摘要和坐标系。操作 CREATE 支持无自动叠加，REFINE 校验显示用当前帧目标 ID 与船 ID。显示叠加 `manual_auto_overlay.1` 不足以证明物理成员或船归属。Raw 行号从过滤非有限值之后的 XYZ 第 0 行起计，同一位置的多次返回保留各行号，支持资格按空间断面/唯一采样计。

## 实验预登记

- 默认搜索沿边端点最大位移 2 m，角偏差 ±5°。范围是人工重画的限界。每侧最多 3 个未排除模式，若超过记录歧义。训练/留出各至少 3 个固定交替断面，联合覆盖 ≥60% 边长；端角保留跨度裕量，跨边索引重叠单独记录。
- 冻结配置见 `manual_review/side_candidates.py`。仅接受可见、具有向外侧顶部平台和分布式立面回波的候选；可见多层与不独立的证据保守降级。无条件补值、搬用自动几何和宽度都不用于测量。相似载荷曲面与遮挡仍须保留拒绝证据。
- 合成开发种子 49072，独立评估 802331；真实扰动种子 19412。干净独立集 20 框×5 扰动，角点最大误差 ≤0.05 m、方向模 π ≤0.5°，100% 唯一。负例错误唯一 0；等价结构拒绝唯一。真实参考每舱平移、旋转、独立尺寸扰动各一次，另列无自动上下文；参考二维接近度仅作独立复核线索。
- 执行预算 5 s，暖提交至证据完成 P95 ≤3 s。固定单线程数值环境；P50/P95 为排序样本最近秩 ceil(p*N)，超时、拒绝和失败全部保留。峰值 RSS 按进程高水位或明确记载的抽样最大分别标识。
- 发布阻断包括冻结源差异、历史参考进入 runtime、错误唯一归属、跨帧、旧成果写入、错误控制字段及真实候选全拒绝。真实操作员签核保持 PENDING。

## 本地入口、事务和证据读取

Windows 运行 `scripts/run_manual_review.bat "输入.pcd" "私有输出"`。Ubuntu 运行 `bash scripts/run_manual_review.sh '输入.pcd' '私有输出'`。入口使用独立 3.10–3.12 环境及单线程数值运行；也可直接执行 `python -m ship_perception.manual_review.server`。退出用 Ctrl+C。端口自动选择，终端打印的随机令牌经 URL fragment 进入浏览器，随后从地址栏移除。服务固定 127.0.0.1，严格检查 Host、写请求 Origin、令牌和显式路由。正文上限 16 KiB，12 个连接处理槽与单匹配槽。

修订采用标准库 SQLite，避免手写断电日志和跨平台文件锁。请求、建议、操作及历史修订分表；事务在比较父修订号、验证稳定候选摘要后一次提交。状态固定存入输出目录下的 mhr_private，重启后按输入内容和配置恢复已提交历史。换会话后，旧视图的未确认建议失效。REFINE 的显示身份与当前帧绑定；现有公开结果缺乏可验证的真实成员行号，此入口保留该限制。MANUAL_ONLY 始终单独标识，缺高程用 null 或 CSV 空字段表示。

每边从旋转带选候选，交替的 0.75 m 半开断面隔离训练与留出。候选中心用每断面等权拟合，留出只复验。候选超过预算显式报告歧义。联合使用固定角与有界五参数解，验查正常量端点位移和原候选盆地，再复验原留出与内部隔板。主结果按原圈选顶点锚定 P1–P4，V0=P1→P2，U1=P2→P3，V1=P3→P4，U0=P4→P1。真实身份未知时保持 LOCAL_ONLY_UNVERIFIED。角部需相邻可观测平台各有独立近角回波，缺测和层竞争分别记录。合成只建模有限荷载、规则围板和已知采样结构。

## 真实轮次裁决

首轮发现整矩形 AABB 请求对密集点云造成预算拒绝，且新入口的 200 万点读取限额早于既有解码器上限。复验改为各边旋转带保留相同的 20 万点运算上限，保留输入文件大小和地图显式预算，恢复既有解码器最多 1200 万点的上限。首轮程序、统计和拒绝证据分别存档。角色、搜索、分布、角点、预算时长和验收精度门均按预登记执行。11 景全矩阵未出现完整 Raw 匹配，主要原因是独立剖面上的物理竞争。真实完整闭环 NO-GO，人工签核 PENDING。当前实验分支用于私有证据复核。
