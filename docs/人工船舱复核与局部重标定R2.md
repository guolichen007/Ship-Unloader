# MHR-R2 自动标定复核与局部重标定

本实验从远端 R1 8195fb3 开始，main 基线为 6af9d759。保留冻结模块和 R1 严格测量入口。工作台默认同一原始帧执行一次原自动入口，或者由本地启动方导入同帧的原始结果目录。历史框仅供私有验收程序生成输入，运行时只接收原始点云与操作员选区。

## 输出绑定

展示和直接确认以 review_hatches_compact.json 的 R3-N 复核层为准，每个 cell_id 仅一条。根据 03_results.json 的 selected_opening_cells 逐值交叉核验复核层选择、角点和尺寸。05_hatch_corners.json 的哈希链接与其严格层逐条验证。严格层和复核层覆盖数可能不同。原样保留显示几何、尺寸、缺失 Z 和原物理资格。确认消费精确几何摘要，无局部计算。

## 局部路径预登记

R1 的原始 57 次扰动、19 次关闭叠加记录均保留，R2 使用同像素合同重放。真实正常样本使用其独立合成圈选输入并标注来源，现场操作员不代签。新增合成反例包含同一围板重复观测、真实不同平行结构、跨舱及长舱端点偏移，旧合成 200 例保持独立口径。

默认根据像素分辨率和粗画位置设定 0.60 m 半走廊，长边的角度放大允许至最多 1.25 m。每一条拟合线两端均须在其走廊内，角度相对圈选不超过 3 度。读取证据另加 0.68 m 内外上下文。求解采用原 R1 交错半米级 Raw 断面，物理资格与分布门保持。经同一 Raw 面支撑、全长端点距离和顶面一致证明后才合并等价候选；遍历共享方向满足的有限四边组合，无唯一组合返回歧义。训练提名和联合求解不使用留出集，最终留出只用于否决。内部隔板扫描按重叠条带穷尽空间走廊，预算受限时不声称完整。有限视域内未观察到隔板不能证明船身份。粗框和当前结果只提供业务归属约束，不能当 Raw 测量。局部完整候选保持 UNVERIFIED 物理船归属，始终无钢边/设备资格。缺观测 Z 从不补值。

暖节点记录成功与拒绝分别统计；现场目标、浏览器与真实成功均独立验收。局部重测未达真实门时保留当前直接确认工作台能力，整轮仍为 NO-GO。

## 一轮诊断后的固定复验

首轮 19 个模拟正常样本全部拒绝。组合预算占 13 个，其余为物理训练不足或证据体积上限。复验前将组合预算计数移到共享方向交集剪枝之后，使用原阈值和原预算。适配层把重复序列化的 Raw 断面改成同侧观测行引用，保留摘要与留出。两项修正均按全体输入启用。原 57 次按原操作回放，另列原 CREATE 圈选以现有目标执行 REFINE 的对照，不改动原分母或标签。
