- FLAT_DECK VGICP 地图 z 单峰（无错层），其退化体现在 accumulated 约 7.7 cm 累积错位，
  与 series.csv 指标一致。

上述量化结果与 series.csv 的 P95 指标互相印证。人工图像目视作为 SITE 阶段的待办项保留。

## 当前精确 SHA 复验入口

以下复验不能用历史报告代签新 SHA。先保存用户修改，使用干净工作树、完整 40 位 SHA；不 reset/clean 强行清理。

```bash
git fetch origin --tags
SHA='<full implementation SHA>'
git checkout --detach "$SHA"
bash ship_perception/scripts/validate_ubuntu20.sh \
  --sha "$SHA" --base-sha 06af2d66262afd828edf2eef72b6ce1bc6969797 \
  --cmake /usr/bin/cmake --ctest /usr/bin/ctest --jobs 2
```

首次依赖与构建见[工程入口](../ship_perception/README.md)。必须 Ubuntu20、GCC9、CMake3.16、Eigen3.3.7、PCL-ON，并记录实际解析的依赖路径。脚本新建 validation/<SHA>/<UTC-run-id>，构建离线，不复用旧 PASS；该目录被忽略，不提交 Git。

按顺序审查验收器反例、PCD 自检、真实后端、地图安全、G5 harness、G1～G7 Quick 和 Full。Full 两后端、17 场景、3 种子、200 帧，至少同一后端贯穿 11 必测场景达标；不逐场景拼接后端，不用 Quick 替代 Full。PCL 已知 SE(3) 必须执行、收敛、有效且达 5cm/0.5°。

审查 pose/quality/map/timing/series CSV、compiled SHA、配置/产物哈希、真实执行与非法输出、静态 P95、revision 和地图污染。稳定 bootstrap 与晋升点均需再次隔离、移出快照、完整恢复并可再次隔离；未观测/遮挡不计冲突。核查初始化质心、shuffle 与容量顺序不变性。
