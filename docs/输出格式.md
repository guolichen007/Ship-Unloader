# 输出格式

## 坐标与尺寸

每座开口输出 `P1～P4` 四角原始输入坐标系的 `(X,Y,Z)`，单位米。以下仅为合成格式示例，不是实景坐标或算法输入：

```text
第1舱｜长20.00米 × 宽10.00米
P1（X=0.00，Y=0.00，Z=—）
P2（X=20.00，Y=0.00，Z=—）
P3（X=20.00，Y=10.00，Z=—）
P4（X=0.00，Y=10.00，Z=—）
```

图中两位小数仅是显示精度；机器JSON保留原始浮点数。缺测Z以 `null` 保存，不补值。坐标文本放在角点旁或图外侧栏，不能遮挡原标定框。

## 主要产物

| 文件 | 内容 |
|---|---|
| `01_geometry_only.png` | 点云几何与结果叠加 |
| `03_results.json` | 完整原生输出与来源信息 |
| `opening_cells.json` | 物理开口身份与成员 |
| `review_hatches_compact.json` | 二维复核建议、证据等级及状态 |
| `05_hatch_corners.json` | 每舱四角XYZ和Z状态 |
| `hatches_compact.json` | 严格几何与长宽 |
| `船舱四角长宽_简表.csv` | 方便查看的角点与尺寸 |
| `船舱复核总览.html` | 中文审图页面 |
| `运行总表.csv` / `全部场景复核.html` | 批次耗时与复核索引 |

程序识别成功与钢边认证成功不是同一状态。二维建议结果保留 `steel_certified=false`、`control_eligible=false`。严格矩形未决时仍可显示复核框，但不能据此认为实际钢边位置已获得认证。
