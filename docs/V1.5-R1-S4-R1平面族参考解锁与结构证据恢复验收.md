## 三个代码层问题的修正（对应 S4-R1 前置要求）

1. **确定性聚类**：`family_consensus.deterministic_families` 用全序排序键 `(-support_count, segment_id, candidate_index)` 替代 P1.5 的 greedy first-match，输入 candidate 顺序打乱后 partition 不变（有单元测试 `test_deterministic_under_input_shuffle`）。
2. **真实 contour 有符号距离**：空间角色改用 Height node 真实 mask 的 `_outer_contour` 多边形，算有符号距离（负=内部，正=外部），四区 `INTERIOR_DEEP / BOUNDARY_INNER / BOUNDARY_OUTER / EXTERIOR_REMOTE`，boundary band 两侧都算（inner 用 `boundary_search_m`=1.5，outer 用 `support_search_m`=4.0）。不再用 AABB。
3. **C2 判定门**：`plane_consensus_evaluator.criterion_2` 改为 `child_votes > root_votes`（首笔提交已修），并加反证测试 `root=100/child=1 → FAIL`。真实数据 root=1、child=37/27/15，修复后仍 P15-D。

## 两级门：Strict Core + Relaxed Attachment

```text
Strict Core   = normal_refine_deg(3°) / plane_inlier_m(0.05m)   —— 必须有 ≥2 个不同 segment
Relaxed Attachment = 2x(6°/0.10m)                              —— 只能吸附到已存在的 strict core
```

- 2x candidate 不能自己创建 stable family（`test_relaxed_attachment_cannot_seed_its_own_family`）。
- 防 chain bridging：family 每吸收 member 后，最终迭代删除任何超出 relaxed gate 的 member，保证最大离散 ≤ relaxed gate（`test_chain_bridging_guard_bounds_dispersion`）。
- representative 用 robust：normal 用 spherical/归一化 robust mean，offset 用 median。
- 全部基于 `n·p+d` 归一化平面方程 + 场景 centroid，不做 constant-Z 聚类（roll/pitch 合成回归覆盖）。

## 参考解锁规则（observed-first）

只允许 `BROAD_PERIMETER_SUPPORT` 作为 profile reference，且必须满足：strict core 存在、≥2 独立 segment、非 `INTERIOR_SURFACE`、非 `ROLE_AMBIGUOUS_OVERFLOW`、非纯 remote、空间连续（`spatial_connectedness ≥ 0.5`）。

对每个 ambiguous segment：先 Hard Gate（参考角色 + strict core + 连续 + 非溢出 + candidate 属于当前 segment），剩一个 → `FAMILY_REFERENCE_RESOLVED`；剩多个按 `unique_segment_votes → unique_node_votes → boundary 覆盖 → 支撑量 → 到 representative 的平面距离` 排序，仍不能唯一 → `FAMILY_REFERENCE_AMBIGUOUS`（fail closed）；无候选 → `NO_LOCAL_REFERENCE_OBSERVATION`。**传入 `_profile` 的是当前 segment 自己观测到的 candidate plane，不是 family 的全局 plane**；从不为未观测该 plane 的 segment 强行推断 reference。

`NARROW_BOUNDARY_STRIP` 本轮同步保存为 `STRUCTURE_TOP_CANDIDATE`（不是 CONFIRMED_COAMING），留给 S4-R2。
