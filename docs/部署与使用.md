# 部署与使用

## 系统要求

- Windows 10/11，或 Ubuntu 20.04/22.04（64位）。
- Python **3.10～3.12** 和 pip。Ubuntu 20.04 默认Python 3.8不满足当前固定依赖，须单独安装Python 3.10。
- 首次安装需要下载 `requirements-ros.txt` 中的依赖；离线PCD使用不需要ROS2、PCL或C++编译。
- Ubuntu中文图形字体可另行安装：`sudo apt-get install fonts-noto-cjk`。

## Ubuntu

先准备与解释器匹配的标准 venv 组件和中文字体。系统仓库提供 Python 3.10 时可执行：

```bash
sudo apt-get update
sudo apt-get install python3.10-venv fonts-noto-cjk
```

Ubuntu20 如使用独立安装的 Python，应安装对应的 venv 支持；不要替换系统 Python 或修改历史冻结环境。网络受限时可设置 pip 的 `PIP_NO_INDEX` 和 `PIP_FIND_LINKS` 使用事先校验的本地 wheel 目录。

```bash
git clone https://github.com/guolichen007/Ship-Unloader.git
cd Ship-Unloader
bash scripts/install_review_env.sh
bash scripts/run_review.sh /data/pcd/sample.pcd ./output --mode full
```

脚本只在项目的 `.local/review-venv` 中安装依赖，不修改系统环境或历史冻结环境。使用自定义Python：`PYTHON_BIN=/path/to/python3.10 bash scripts/install_review_env.sh`。批量处理时传入目录：

```bash
bash scripts/run_review.sh /data/pcd ./output --mode full
```

## Windows

安装Python 3.10（带 `py` 启动器）和Git后，在命令提示符执行：

```bat
git clone https://github.com/guolichen007/Ship-Unloader.git
cd Ship-Unloader
scripts\install_review_env.bat
scripts\run_review.bat "D:\pcd\sample.pcd" "D:\pcd\output" --mode full
```

Windows 自定义解释器：先执行 `set "PYTHON_BIN=C:\path\to\python.exe"`，再调用安装或运行脚本。路径可含空格。已有环境也可跳过安装，直接设置该变量运行。

## 运行方式

`--mode full`：单次完整精修与数据发布；`--mode staged`：先预览、再利用快照续跑；`--mode preview`：只预览。`--rounds 3`表示三轮重复验证。输入坐标系可由 `--frame-id` 标记，参数不会转换物理坐标。

输出根目录可重复使用。每次调用创建 `run_<UTC时间>_<随机编号>`，并打印 `RUN_ID` 和 `RUN_OUTPUT_DIR`。以终端打印的 `REVIEW_INDEX` 打开本次复核页；`运行总表.csv` 的 `result_dir` 指向本轮通过检查的结果。每场的日志、收据和 staged 快照随本次运行保留。

单景失败记入运行表后继续下一景。Ctrl+C 标记本次批次为 `INTERRUPTED` 并停止后续场景，退出码为 130。进程被强制终止时可能留下 `RUNNING` 状态，读取时应依据 [输出格式](输出格式.md) 判断完成情况。

## ROS2单帧采集（可选）

仅在Ubuntu22.04/ROS2 Humble环境配置完成后运行：

```bash
source /opt/ros/humble/setup.bash
bash scripts/run_ship_hatch_once.sh --topic /ship_scan/map --qos auto \
  --output-dir ./output --mode review-first --opening-topology-v2 --local-rim-review
```

示例显式启用完整离线复核链；底层 CLI 默认保持 `bounded`。如多船并列，应提供可靠的现场泊位参考或人工选船ROI。无可信参考时，不能猜选目标船。离线复核输出不具备自动电机/PLC控制资格。
