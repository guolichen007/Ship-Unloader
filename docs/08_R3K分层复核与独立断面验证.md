# R3-K 分层复核与独立断面验证

状态：实验分支，未生产放行。适用版本：R3-K。日期：2026-11-12。Owner：Ship-Unloader Engineering。

本轮用户任务以 R3-J `8ca600b` 为基线，明确授权空间核心与二维复核估计层；保留开口身份、严格矩形求解、钢边证据及缺测高度合同。V1.4、B2、Golden12 冻结不变。

`opening_interior_support` 从当前 Cell 的二维占据与边界距离提取空间核，允许多个高度面共存。原始所有权不变，其余成员显式列为边界不确定带；空间核不是钢面接触证明。无可靠核心时保持未决，禁止空集合通过。

`review_side_evidence` 在当前船体 U/V 内沿四个方向搜索，旧边不是唯一搜索中心。按现有物理断面交替分配训练与留出：只用训练提名和拟合；留出仅验证位置、相对高度极性及货脊反证。记录两组来源、原始索引、覆盖率和观测区间。区间包含栅格及矩形近似不确定性，尚非传感器标定区间。

`review_geometry_recovery` 仅在同船多舱异常时触发。各边必须具有本舱独立证据；同船信息仅打破合格候选的平局并施加弱宽度兼容因子，真实异宽可保留。单舱及不同船不共享宽度信息。竞争证据未决时保留互斥备选。矩形必须不丢空间核心、不新收邻舱成员、不越隔板；边界重分类原始索引完整保留。

三个结果独立保存：

- `geometry` 与原 `hatches_compact.json`：原严格结果与原始 XY/Z，不被复核估计覆盖。
- `review_geometry` 与 `review_hatches_compact.json`：操作员复核建议，可为 REVIEW_ESTIMATED；变更 XY 后 Z 为 null，禁止移用旧位置高度；禁止生产控制。
- `steel_certified_geometry`：无外部真值时始终 NOT_CERTIFIED。

主图显示复核建议，细虚线保留原基线。中文 CSV 显示建议坐标；机器严格接口仍保留。`复核层逐边留出证据.json` 保存独立来源，旧严格逐边证据另存。文字排版只读取几何。

Windows：`scripts\run_R3H_windows.bat <PCD或目录> <输出目录> --mode staged`。Ubuntu：`bash scripts/run_R3H_ubuntu.sh <PCD或目录> <输出目录> --mode staged`。失败记录后继续下一景。完整输出包括中文复核图、四栏对照、两层 JSON、长宽/XYZ CSV、性能报告与汇总 HTML。

验收应分别报告开口拓扑、人工二维复核、外部钢边精度及刚体等变性。独立人工签审前 REVIEW_GEOMETRY_GATE 为 NOT_VERIFIED，估计数量不等于认证数量。未经盲标外部真值，STEEL_PRECISION_GATE 为 NOT_CERTIFIED；不得用留出轮廓残差代替钢边精度。

运行产物、客户数据及绝对开发机路径不提交 Git。真实回归、反例与性能结果应记录精确源码 SHA；已知失败保存并单列，不修改验收门以通过。
