## 对五个问题的回答

**Q1 Normal6 是否存在稳定的跨 segment 共面 plane family？——存在，但依赖阈值尺度。**

在配置自然尺度（`normal_refine_deg`=3°、`plane_inlier_m`=0.05 m，1x）下，聚类把 4-16 的 647 个候选分到 509 个 family（410 个单例），8-22 的 892 个分到 669 个（520 个单例）——共识偏弱。把尺度放松到 2x（6°/0.1 m），4-16 降到 305 family（≥3 段票 69 个，最大 family 15 段），8-22 降到 402（≥3 段票 84 个，最大 16 段）。**稳定跨 segment family 确实存在**，但需要比单平面精化更松的共面尺度（甲板跨船有 0.1~0.2 m 高度起伏与几度法向离散）。这是 S4-R1 的阈值设计依据，不是本轮调参。

**Q2 共面 + 空间角色/形态能否区分规则钢结构候选与货面候选？——能。**

角色按空间支撑（inside/boundary/outside 相对 Height node 框）+ 相对宽度给 `ROLE_HYPOTHESIS`：`BROAD_PERIMETER_SUPPORT` / `NARROW_BOUNDARY_STRIP` / `INTERIOR_SURFACE` / `REMOTE_PLANAR_STRUCTURE` / `ROLE_AMBIGUOUS[_OVERFLOW]` / `UNKNOWN`。4-16 有 74 个结构角色 family、8-22 有 374 个；合成反例 A 证明「平滑满载沙坡」即使跨多段共面，也会被判为 `INTERIOR_SURFACE`（内部货面）而不是钢结构。

**Q3 6-8 的 giant root 是否缺少可信结构共识，而真实 child/fragments 更合理？——是，且差距很大。**

结构角色 family 按 node 归属统计：giant root `l03-c0002`（baseline 所选）只有 **1** 个结构 family，而 child/fragments `l01-c0009`=37、`l02-c0001`=27、`l02-c0006`=15。giant root 覆盖面积大但没有任何结构共识优势，反证了「大面积 ≠ 结构更强」。

**Q4 满载平滑沙坡、溢料、船体 roll/pitch 能否击穿错误判定？——不能，全部 fail-closed。**

三个合成反例全过（见下）。溢料跨 interior→boundary→exterior 且无独立窄结构带时判 `ROLE_AMBIGUOUS_OVERFLOW`（PARTIAL/UNKNOWN），不自动补钢边；roll/pitch/yaw/translation 后 family 归属与角色关系完全一致。

**Q5 跨舱 plane consensus 是否具备「可能漏掉舱口」的信息价值？——具备，但仅作为诊断观察项。**

8-22 存在 82 个跨 node 的结构 family（如 `f007` BROAD_PERIMETER_SUPPORT 横跨 5 个 node：`l00-c0002 / l01-c0019 / l01-c0020 / l01-c0022 / l02-c0004`），构成 `CURRENT_SHIP_INTERNAL_CONSENSUS`。`POSSIBLE_MISSING_HATCH_REGION` 本轮输出为空列表，仅作为未来漏检恢复的观察项，不自动新增 Hatch。

## 三个合成反例

| 反例 | 期望 | 结果 |
| --- | --- | --- |
| A 平滑满载沙坡（跨多段、法向一致） | 稳定 family 但不判钢结构 | PASS：判 `INTERIOR_SURFACE`（非 steel） |
| B 货料溢过围板（interior→boundary→exterior 连续、围板遮挡） | `ROLE_AMBIGUOUS_OVERFLOW` / PARTIAL | PASS：`ROLE_AMBIGUOUS_OVERFLOW`=1、steel=0 |
| C 整体 roll/pitch/yaw/translation | 归属与角色几何等价 | PASS：旋转前后 family 归属 + 角色完全一致 |

旋转不变性专门验证了聚类用的是 `n·p+d`（归一化平面方程 + 场景 centroid 平移后的 offset），而不是 constant-Z 聚类。

## 空间角色与 fail-closed

- 角色是 `ROLE_HYPOTHESIS`，不是物理真值；Height node 可能错误（尤其 6-8 giant root 内部含船外/水域/码头），因此 `spatial_role` 只生成假设，最终靠 topology / cross-node consensus / structural continuity 再验证。
- `INTERIOR_SURFACE` 不删除：它是 `OPENING_EXISTENCE_EVIDENCE` 与 `PROFILE_DIRECTION_HINT`（低料/空舱 PLY 中内部低区本身支持「这里存在 opening」），满载时可变弱但不当硬必要条件。
- 溢料 fail-closed：平滑面连续 INTERIOR→BOUNDARY→EXTERIOR 且无独立窄结构带/face/结构线分隔时，判 `ROLE_AMBIGUOUS_OVERFLOW`，保持 PARTIAL/UNKNOWN，不硬分甲板/围板/钢边。有单元测试。
- 禁止假设：`Cargo<Deck`、`Cargo residual>Steel residual`、`Stable plane=Steel`、`Highest plane=Coaming`、`Largest plane=Deck`、`Observed top-strip required` 全部不进入产品。

## P15 判定与下一阶段方向

五项判据全部满足：

```text
c1 4-16 / 8-22 出现稳定可解释 PlaneFamily           = 是
c2 6-8 giant root 不因大面积获得虚假优势              = 是（root 1 vs child 15~37）
c3 平滑满载沙坡不被仅凭共面性判成钢结构              = 是
c4 溢料 fail-closed                                 = 是
c5 roll/pitch 后结果几何等价                         = 是
```

故 `P15_DECISION = P15-D`。S4-R1 的真正作用（本轮不实现，仅记录）：用 PlaneFamily 共识解除当前 `SEGMENT_DECK_AMBIGUOUS → profile 不执行` 的死锁——`candidate planes → PlaneFamily consensus → 可信 reference-plane hypothesis → 对 segment 解锁现有 _profile`，同时把 `NARROW_BOUNDARY_STRIP` 作为新的结构 evidence。Plane consensus 是为了让现有 profile 链活起来，而不是取代它。
