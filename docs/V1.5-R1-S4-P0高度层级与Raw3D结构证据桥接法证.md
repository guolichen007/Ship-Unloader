# V1.5-R1-S4-P0 高度层级与 Raw3D 结构证据桥接法证

## 范围与出处

从 `e7e01fc152f318941aa335fd2ebf28c6616dd972` 建立分支 `feature/v1-5r1-height-structure-forensics`。只增加研究侧法证适配器、独立弱标注评估器和测试。未修改 `heightmap_topology._choose()`、`_nodes_at_level()`、`_combine_fragments()`、研究参数、生产周边段/局部水平支持/边界精化规则，也没有把碎片合并为 Hatch。

正式运行目录：`Ship-Unloader-Work/r1_height_structure_forensics/baseline_005_p0/`。算法仅以 Normal6 清单中经 SHA 校验的原始 PCD 与 baseline_004 固定配置为输入。每场景先重建完整 Height hierarchy，再将每个 node 的**真实 mask**经 `SeedComponent → OpeningSeed → perimeter_segments → estimate_segment_deck → refine_perimeter_boundaries` 走现有 Raw3D 链。轮廓 PLY 的 Z 值仅用于显示，高度为 node 代表高度；它不是观测钢边。观测边单独保存在 profile/face PLY 与 JSON 中。

baseline_004 的六场景所选 node ID、框、score、区域数均逐项一致。评估器在六场景 `node_structure_audit.json` 和 PLY 全部写盘后先记录文件 SHA，再单独打开标注；重复文件别名没有重复计分。弱标注和场景名均不进入检测/法证模块的候选选择。

## 6-8 / 7-16 碎片关系与边界恢复

跨层关系使用真实 mask 的主方向、长短轴投影、mask 重叠和现有观测结构线。`fragment_compatibility.json` 保留每对独立字段，不计算 composite score，不使用标注生成配对。

6-8 中 `l02-c0001`（南部约 `y=0.5–4`）与 `l01-c0009`（北部约 `y=11.5–27.5`）在长轴上重合，但真实 mask 投影之间约有 **8.68 m** 间隔，北部节点未形成观测边。两者只能判为 `AMBIGUOUS`，不能因 AABB 能包住间隔而称为同一 Hatch。7-16 的跨层节点相互重叠或嵌套，结构线也不足以解释为互补碎片。两场景均为 **0 个 `COMPATIBLE` pair、0 个 `RECOVERABLE_FROM_EXISTING_STRUCTURAL_EVIDENCE` group**；对 `AMBIGUOUS` pair 的 `boundary_recoverability` 保持空值，不偷换成已完成或已否定的边界。
