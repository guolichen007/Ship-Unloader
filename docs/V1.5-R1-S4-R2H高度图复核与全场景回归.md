# R2H 原始 XYZ 高度图复核与全场景回归

## 范围与证据语义

本轮修复 B5 多舱递归分组后的相邻舱上下文丢失，并为静态审图加入 Raw XYZ 多纵向剖面的高度突变复核。高度突变只能提示开口位置，不能单独认证钢结构内沿。原 B5 `polygon_after`、边界角色和 acceptance status 不被高度复核覆盖；复核多边形单列在 `height_rim_review` / `height_review`，状态为 `HEIGHT_TRANSITION_REVIEW_NOT_STEEL`。没有独立内沿 Golden，不声明静态厘米级标定通过。

## 根因与修正

1. **8-22 中舱截短**：`solve_vessel_openings` 把相隔的舱分成独立递归组后，弱边仲裁只能看到当前组。H000 U1 的 B4 混合上下文边约 22.42 m 覆盖不足；原 R2G 候选约 24.34 m 有更强开口关系。递归传递同船 opening context 后，仲裁恢复约 24.34 m。共享证据只用于判断邻舱位置，不跨舱确认钢边。
2. **4-16 图上偏斜**：旧展示用 B2 船体轴投影原始点云，却叠加 B4/B5 轴上的矩形，两轴约差 1.74°。展示现采用矩形求解轴。Raw XYZ 多剖面还显示残余轴向漂移，因此高度审图可在全船统一的小角度范围内复核；所有同船舱共用一个轴。
3. **4-22 上下边漏覆盖**：B2 局部候选的 V0/V1 缩在开口内。高度图多剖面在两舱分别得到约 V0=4.0–4.1 m、V1=16.1–16.3 m 的持续突变，审图矩形覆盖了原高度图中更完整的开口区域。两舱保持 `PARTIAL`/待复核，不升级为钢边已确认。
4. **弱边过移风险**：7-16 的码头邻边、08-08 的外侧低边和 6-8 的货物高差会产生强高度突变。对既有 B4/B5 边，大幅向内移动或超过现有搜索尺度一半的移动均拒绝；轴向只从通过门限的上边剖面估计。拒绝原因和候选偏移保留在 JSON。
