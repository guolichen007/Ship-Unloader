# V1.5-R1-S4-R2H-B5：角点拓扑第一笔法证

## 范围与版本

- 基线：`feature/v1-5r1-scene-vessel-hypothesis`，`6bfc6371666fed6f89ec5c008ff4607da7bf3ae0`。
- 本笔只加只读法证、图和合成反证；正式 B4 几何、角色和 acceptance gate 未改变。
- 输入以 manifest、B2、S3 的原始 PCD SHA256 一致性核验。输出在被 Git 忽略的 `Ship-Unloader-Work/review/r2h_b5_forensics/`。
- `MEASURED_INTERSECTION_CANDIDATE` 表示两种测线在二维投影中相交且有局部高差。它**不是**已确认的 `MEASURED_HATCH_CORNER` 或钢结构内沿。

## 代码链与历史能力

| 阶段 | 仍有价值的能力 | 目前缺口 |
|---|---|---|
| S3 | 多高度层、开口 basin 与层级区域主动定位 | 层级 JSON 是区域包围框，不含各高度层的局部轮廓角点坐标；无法由其证明空间持久角点。 |
| B2 | Raw3D/BEV 实测线和 per-vessel provider 来源 | HatchHypothesis 可能横跨多个真实开口。 |
| R2F/R2G | 轴对齐矩形、原始证据融合和内沿 rho 精修 | 对错误初始边的局部搜索半径有限。 |
| B4 | 局部内外高差、保守 `PARTIAL/UNRESOLVED`、08-01 共用底边 | `corner_support_count` 在已有框角计算，是事后诊断；lineage 各框独立最大 IoU；side provider 仍可接收 `UNRESOLVED` 上下文。 |

法证读取 S3 区域作为搜索 ROI，读取其高度层作阈值对照；**未**重放 S3 的逐层轮廓或获得角点位置的空间持久性。输出 `persistent_corner_count=UNVERIFIED_SPATIAL_PERSISTENCE`。B5 第二笔要从各层实测轮廓计算同一角点的位置分散度，不能把跨层高差计数冒充角点持久性。

## 关联法证

08-01 的 B4 `H000`、`H001` 都指向 `V0001:H0001`，IoU 分别约 `0.411`、`0.384`。B2 的这个 proposal 轴向范围 `[-90.69, 5.52, -16.69, 17.52]`，横跨两个 B4 开口。逐框最大 IoU 产生重复占用。只读的一对一审计识别其为复合 proposal，两个 B4 开口均标记 `UNMATCHED_OPENING`，等待角点图拆分；没有把其中一个随意归给复合 proposal。08-08 的 B4 框本来就没有 B2 lineage，当前也保持 unmatched。

这揭示两个独立问题：一对一 assignment 必须显式允许 unmatched；B2 复合 proposal 要按 opening topology 拆分，不能只以 Hungarian 匹配掩盖原始 proposal 跨舱。

## 08-01 角点图

- B4 的两个矩形共用 `V0≈4.638 m`；B4 的 U 链约 `-86.470 / -55.562 / -18.882 m`，现有两舱长度约 `30.907 / 36.680 m`，长度先验未使用。
- B2 实测 U 模式的就近候选约 `-86.65 / -56.20 / -18.70 m`；中间模式有 Raw3D 和 BEV，但这只证明一个横向结构候选。法证图列出其上下两个交点。
- 当前简单交点/高差排序把 `V0≈7.49 m`、`V1≈17.61 m` 列为并列第一类；该 `V0` 明显高于 B4 已改善的底边。`272` 个候选组合中有 `140` 个同分。交点数 6 不是“六个真角点”。
- `V0≈4.638 m` 旧边仍保留在组合列表中，不能因短名单而消失。B5 第二笔必须加入局部 L 形延伸、inside 象限、结构跨层位置稳定和共享 separator 的联合约束；当前排序不可用于移动正式边。

## 08-08 平行边法证

- B4 的 `V0≈1.950 m`、`V1≈12.920 m` 处于 multimode conflict。
- B2 测线调查出现 `V0≈3.85–5.88 m` 和 `V1≈11.77–14.29 m` 的多条近邻模式；旧边作为 baseline 也参加组合。
- 最高的诊断组合 `V0≈3.85 m`、`V1≈13.86 m` 仅有 3 个结构交点候选，左下角只有高度/结构单项证据；`357` 个组合中 `42` 个最高分并列。`pair_resolution_status=NO_FOUR_MEASURED_INTERSECTIONS`。因此还没有证据宣布 `V0=3.85 m` 是真内沿。
- 高料可在开口内部高于外侧；合成反证验证相对高差在 Z 整体平移后不变，不能使用“内部一定低”硬门。

## 证据纯度与测试

法证分别记录同 Vessel Raw3D/BEV coverage 和 `UNRESOLVED` 上下文 coverage；混合模式显式标为 `MIXED_PRIMARY_AND_CONTEXT`。上下文不计入角点的结构交点测量。正式 B4 `_provider_lines()` 仍会接收邻近 `UNRESOLVED` 测线，这是待 B5 第二笔修正的真实红项。实际 B4 输出里，08-01 `H001.V0`、08-08 `H000.V0` 的已选线只来自 `UNRESOLVED V0000`；08-01 `H000.V0` 混用了 `V0000` 与确认船 `V0001`。这解释了为何只用当前 Vessel 的 B2 测线时，旧底边被列为 `OLD_R2G_BASELINE_ONLY`：它仍可能是有效物理边，但目前证据所有权没有完成验证，不能因 B4 已采用就默认为已确认钢边。

`test_r2h_b5_corner_red.py` 有 12 个合成例：7 个当前法证保护项通过，5 个明确标记 `expectedFailure` 的 B5 未实现契约：平行假边得分并列、旧框外重定位、一角遮挡的 PARTIAL 语义、正式重复 lineage、未决结构供线。`expectedFailure` 保留测试套件绿色并使缺口可见；第二笔实现后应逐一移除该标记。另有多舱共享、长度不等、船外 L 角、高料 Z 平移、纯高度角点和 B4 source 审计的保护项。

验证：Python 全量 222 项通过（其中 5 项 B5 契约为预期失败）；CTest 非 quick 的 39 项中 38 项通过，旧 `g5` 因无合格后端失败；`v14_frozen_paths` 通过。`v15_quick` 的 synthetic PASS，real smoke 因 4-16 `FRAME_UNRESOLVED` 失败，integration 因 `STALE_BINARY` 失败；它们不用于调整静态 B5 角点阈值。

- `CORNER_TOPOLOGY_GATE=UNRESOLVED_NO_SPATIAL_PERSISTENCE`
- `MULTI_HATCH_ADJACENCY_GATE=FORENSIC_GRAPH_ONLY`
- `SIDE_EVIDENCE_PURITY_GATE=FAIL_CURRENT_B4_UNRESOLVED_CONTEXT_CANDIDATE`
- `INNER_EDGE_GOLDEN_GATE=UNVERIFIED_NO_INDEPENDENT_GOLDEN`
- `ALGORITHM_CHANGED=NO`；正式框仍为 B4 输出。
