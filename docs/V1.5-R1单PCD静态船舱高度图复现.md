# 单 PCD 复现静态船舱高度图

在仓库根目录运行以下命令。每条命令只读取原始 PCD、仓库配置和当前源码；无需预先运行旧版高度图，也不读取历史中间 JSON。

```bash
python -m ship_perception.r1_static.pcd_showcase \
  --pcd Ship-Unloader-Data/legacy/hold_detector/detect/test/2026-08-08-02-33-57.pcd \
  --scene-id 08-08 --output Ship-Unloader-Work/review/直接PCD验证/08-08 \
  --expected-sha256 28ab75a172a6e0d270e822cb66225c7fe09e8fbe8ecc39513cbeb3608d129c2f

python -m ship_perception.r1_static.pcd_showcase \
  --pcd Ship-Unloader-Data/legacy/hold_detector/detect/test/2026-08-01-05-09-32.pcd \
  --scene-id 08-01 --output Ship-Unloader-Work/review/直接PCD验证/08-01 \
  --expected-sha256 ea736584c7d3815fec90a2bb6d7f1fd615c016452afaba083a75a4057c1cffb2
```

Windows PowerShell 可将每条命令写成一行。缺少原始 PCD 时，从私有数据目录取得相同 SHA-256 的文件；原始数据和输出图均不提交 Git。Linux 上如中文显示为方框，安装中文字体或设置 `SHIP_SHOWCASE_CJK_FONT` 为本机字体文件路径。

输出主要包括 `原始XYZ高度_船舱候选单图.png`、`高度图审查数据.json`、`corner_topology.json` 和 `运行摘要.json`。图中的虚线表示待复核候选，`UNVERIFIED_NO_INDEPENDENT_INNER_EDGE_GOLDEN` 不等同于厘米级内沿精度验收。

2026-10-15 在 Windows 上以上两个 PCD 的候选数分别为 1、2，候选框坐标与 `Ship-Unloader-Work/review/船舱标定图/` 完全相同，PNG SHA-256 分别为 `c58456ae7e39518a0da76b2ec48d509912b2b0bf635b37c654c24de3f8392c47`、`eb857f374d2efabd541eef903ae329cb48bd955db513bb7d173bca214b9ba2b6`。不同系统的字体和 Matplotlib 版本可能改变图片字节；跨设备以输入 SHA、候选数量、角点坐标和 `高度图审查数据.json` 为主要对照。

较早的 `船舱静态标定效果展示` 是历史输出，图像文件与最新 `船舱标定图` 不同。本入口复现当前源码的最新输出，不回放历史图像。
