# 测试与使用限制

## 已完成的验证

R3-N源码基线 `dfd04f0221090bb51477fc24eb044f269f86d28d`：11场原始PCD反复运行110次，19个主开口与几何摘要一致；44个稀疏裁剪保护保持；Windows和Ubuntu 20/22跨平台密度舍入误差已修复。GitHub对应源码SHA的ROS2 CI通过。

## 保留的工程限制

- 有效刚体变换最大偏差约10.06厘米；08-02旋转输入后有合舱反例。
- staged完整CLI P95为98.893秒，高于研究目标95秒；cold P50为48.247秒。
- Windows原生Quick仍有未通过项；CI不覆盖全部真实PCD及现场Quick。
- 4-22两个开口严格矩形不可解；部分边缺少平台见证或存在平行多解。
- 钢边厘米级精度、全量Z测量及陌生船型泛化没有独立认证。

当前使用范围限于离线二维人工辅助复核，不构成钢边精度或现场自动控制认证。人工审核记录独立维护，未完成的审核不代填通过。
