## 3. Schema v2 层级

```
scan
├── scan_id / source_pcd_sha256 / split_role
├── scene_review_status / operational_target_vessel_id (可 null)
├── vessels[]
│   ├── vessel_local_id / roi_raw_xy / vessel_role
│   ├── fov_coverage
│   ├── visible_in_fov_hatch_count   ← 视野内舱数
│   ├── whole_vessel_hatch_count     ← 整船舱数（可为 UNKNOWN）
│   ├── count_certainty
│   ├── subdivision_evidence[]       ← CONFIRMED_PARTITION / TRACE_ONLY / NO_PARTITION_EVIDENCE / UNKNOWN
│   └── hatches[]
└── reason
```

- `vessel_role ∈ {PRIMARY_DEVELOPMENT, MULTI_VESSEL_STRESS, PARTIAL_FOV, UNRESOLVED}`。
- **视野内舱数与整船舱数彻底分离**，不得共用一个字段。
- `subdivision_evidence=TRACE_ONLY` 不得转换成两个 Hatch；`4-16` 的 `operational_hatch_count=1` + `physical_partition_confirmed=false`。
