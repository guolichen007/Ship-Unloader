## 几何与原始证据

XY 网格锚定当前最小 XY，统计 count/q10/median/q90/min/max/occupancy；空白不提供观测。多层高度、局部环带与 basin 提出粗开口，不把高度框直接当围挡。

Local/Perimeter Deck 使用候选外围且结构连续的实测点；Cargo interior、Wharf、未知空白、竞争平面和单侧支撑不足不能靠 Global Deck fallback 变成功。规则平面族区分 strict core、relaxed attachment 与空间角色，Cargo/Overflow 或未知角色不能承担钢边确认票。

Raw3D profile break 与竖直 face 保留测量来源、实际支撑区间和拒绝原因；`RAW3D_VERIFIED_VERTICAL_FACE` 只证明几何面，`MEASURED_INTERSECTION_CANDIDATE` 只证明投影交点候选，均不直接认证钢材或舱角。

矩形融合沿已有正交轴组合多候选；内沿精修只处理已有矩形，不恢复从未提出的开口。保留去重前 rho、连续 RawXYZ/Raw3D、独立截面、中位数与 MAD；持续的两个平行 mode 不能被一个 median 掩盖。低覆盖、大位移、角色冲突或更强实测不足时回退原边，记录原因。现有排序与阈值不因本轮治理改变。

宽度一致性只在显式同一 Vessel ID、有实测强边时作最后平分；不跨船或未知身份，不创造观测，不强制双舱等宽/等长。08-01 的宽差曾来源于不同物理角色与 rho，而非可直接修正的等宽真值。

## Scene、边角色与角点

空间 component 不能等于船；方向族、支持与船体角色分别追溯。逐船 BEV/Raw3D 不以 Height 非零为调用前提，但现场总编排仍复用早期 Height/R2F/R2G 初值，最终召回尚未完全解耦。邻近 UNRESOLVED context 或其它已确认船的测线不能计为本船钢边观测。

足迹内低舱点回填避免高层 shell 掩膜把内部测量删除；footprint 不等于钢边。持久角点检查跨高度层的位置、局部 L 形与象限占据，不以高差次数替代空间持久性。相应 PARTIAL 闭合需至少三个可追踪角点，缺角保留 INFERRED_GEOMETRIC_CORNER，不能改为实测。

同船多舱共享 U 隔板链，允许不等长；分离开口分组仍传递同船上下文，避免跨间隙假 cell。复合 Proposal 的一对一 lineage 允许 unmatched，不能用匹配掩盖跨舱 Proposal。无有效边对/角点组合时保留 UNRESOLVED 和已有审查几何。

离线 `b4=None` 的 B2 bootstrap 与现场传入空 B4 字典不同，不能因此声称所有无初始矩形场景都已有最终开口。B4 的局部内外高差、高料关系与 B5 的角点/隔板均仅按现有代码提供证据，不替代 Golden。

## 高度复核与展示

原始 XYZ 多纵向截面寻找持续高度过渡，所有同船舱共用小角度轴向复核。显示轴与框一致；弱边大幅内收、跳向码头或货物高差受既有位移和结构门限制。原 polygon_after、边角色和状态保留；height_review 另存图示多边形与 HEIGHT_TRANSITION_REVIEW_NOT_STEEL。

背景为原始中位高度，琥珀框、H 编号、虚线与“待复核”只表示候选，不改变证据身份。现场只请求两张图；旧研究绘图源码继续保留。

## Intensity 辅助

同一次输入共享 XYZ providers，再分别运行几何和强度辅助复核；baseline 不使用强度。在 B1 船体归属点中取 P5/P50/P95 与 MAD，以 P5/P95 裁剪归一化到 0～1，建立中位强度网格。记录 U/V 梯度、两侧差异、沿边符号一致性和成对占据支持率；角点要求局部 U/V 双向变化。空格与无效强度不提供支持票。

现有 `AUX_WEIGHT=0.05` 不变，只加到 V0/V1 排序中结构可行性、类别与截面支持等离散证据之后的连续尾项。原几何门、角点数量、货物多模式拒绝和角色不变；U 端边和角点额外证据供审查。不得以绝对强度阈值判钢、单独产生舱或认证钢边。强度有值不意味着框必定改变。

缺失/全无效强度走明确 fallback；无船体或无 robust 对比标不可用，不破坏正常 XYZ 结果。所有统计、使用状态和拒绝信息写 JSON，不单独画强度图。

## 从过程文档迁入的结论与限制

S1/S2 的局部甲板竞争与周边支撑、S3 的多层高度、P0/P1 的 profile 可观测性、平面族角色纯度、R2R 点级来源、R2F/R2G 多模式回退、R2H 逐船隔离、B4/B5 角点/隔板和高度复核已整合进上文。历史图表与单次参数记录从 HEAD 删除，源码、测试、配置与 Git 历史保留。

Normal6 的 2/1/1/1/1/3 是开发候选数，不是钢边精度。多船、复合 Proposal、缺端角与局部 FOV 仍有最终召回缺口；5-21、5-29、7-2、7-15、08-02、8-17 的历史审查未形成完整可信最终开口，4-22 的两个 PARTIAL 只支持复核。

08-01 共边、08-08 平行弱边与 6-8/7-16 的 Cargo/Wharf 高差需独立 opening inner-edge Golden。保持 `STATIC_CALIBRATION=UNVERIFIED_NO_INDEPENDENT_INNER_EDGE_GOLDEN`。本入口没有自动开/闭舱分类、目标船选择、CurrentShipModel 或控制输出。
