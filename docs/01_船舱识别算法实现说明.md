# 船舱识别算法实现说明

适用：当前单帧复核工具。以下是运行链与证据契约，不是钢内沿精度或商业泛化认证。

## 入口与主链

`io/frame.py` 统一不可变有限点数组和输入身份；`io/pcd_source.py`、`io/pointcloud2_codec.py` 分别解码文件与消息。`ros2/pointcloud2_source.py` 只负责 ROS2 图、QoS、订阅和清理；算法不 import rclpy。

`perception/pipeline.py` 按 Recall → Validate → Precision 调度。输入校验后执行一次 B1，将船体 ID、原始点索引及哈希、bbox、轴、support ID、分类、输入 semantic/wire 身份、配置和软件 SHA 冻结为 `SceneEvidenceContext`。后续阶段消费同一归属，不再重新分船后仅靠点数比较。

逐船主链在 `vessel-local UVZ` 工作，输出再转换回输入 XY。原始输入 frame、船体轴、UV 边界、XY 最佳边界、显示边界和变换来源分别保留。UNRESOLVED 船体若有充分几何支持，可输出 `UNRESOLVED_VESSEL_REVIEW`；这不会把船体角色变为已确认。

## Recall：独立局部证据

`local_evidence.py` 缓存每船 coarse/fine 高度格及 BEV/Raw3D providers。高度级别由全部实测局部高度族与 ring/shoulder 产生，先聚类，再扫描低盆地与高料区域；不依赖全局 `chosen` 或 strongest-relative-score。单个完整盆地可提出候选，三边与缺测候选保留 diagnostics。

`recall.py` 关联局部高度区域、实测平行线和同船 provider。粗阶段只去重接近的四条搜索站位；大粗框不能仅凭面积或短边更长，先压掉较小的真实开口。重叠物理候选在 Raw 精修后按逐边支持和一致性取舍，保留被抑制来源。

内部隔板处于 `AMBIGUOUS_TOPOLOGY` 时，四条外边的支持不能证明其内部只有一个舱。具有合格外围原始点支持的对象保留为 `UNRESOLVED_OPENING_GROUP`，记录 `HATCH_COUNT_AMBIGUOUS`、`individual_hatch_count=null` 和阻断原因；外围仍按原有四边流程精修，不能把删除外围后暴露的竞争货堆拆分当成独立舱。`precision_admission` 分别统计提案、拓扑歧义及 Raw 精修尝试数。输出的 `review_candidate_count` 是复核对象数；兼容字段 `hatch_count` 也沿用此含义，不能解释成已确定的真实舱数，`hatch_count_status` 会明确歧义。

现有 `r1_static/pcd_showcase.py`、R2F/R2G、B4/B5 保留为显式比较证据，默认开启以检查既有数据。它与主链共享同一冻结归属，失败不会抹掉已成立的局部候选；`--no-legacy-evidence` 可独立验证新链。不能把合成独立召回通过解释为所有真实船已不需要比较证据。

## Validate：船外、归属与包围

`validation.py` 建立 observed、owned、low-region 和 exterior-low 拓扑。低区域只沿实际占据格做连通；missing cell 不能变成通道。场景边界、未归属当前船的实测低格是外部种子。明显重叠且外连的低区拒绝为 `REJECT_EXTERIOR_LOW_REGION`；少量局部外连或裁剪不明保持 `UNRESOLVED_EXTERIOR_CONNECTIVITY`，不能认证。

没有固定水面 Z。标签是外部连通低区，不强行猜测 WATER。缓存按内存预算淘汰只影响重算，不量化实际测试高度或更改阈值。

Containment 分别检查候选中心、四角与观测支持/船体包络；插值或填洞只用于说明包络，不计为观测。明显船外拒绝，边界缺测保留 PARTIAL。`DeckRingEvidence` 逐边记录同船 ID、signed height transition、Raw3D、BEV、face、覆盖区间与占据支持。附近有结构线不等于水面内有船舱。

Raw3D 的几何面、BEV 的线和高度转折都不单独认证钢边。`RAW3D_VERIFIED_VERTICAL_FACE` 仅为几何提供者标签；货物坡面也可能产生强响应，仍需开口方向、包围与原始多截面核对。

## Precision：唯一四边精修

`FinalBoundaryRefiner` 对 U0/U1/V0/V1 使用完全相同的流程，融合已有 `_raw_edge_rho()`、`_continuous_rho()`、`_section_transition()` 和 Theil–Sen 共识。网格定位搜索区域，最终 rho 优先来自 Raw XYZ 的成对转折与合格 profile。稀疏 0.05 m 格没有成对占据行时，仍检查原始点，不让 raster aliasing 否决真实边。

沿边按物理长度、分辨率和占据支持自适应分段。短边不硬切成五段，长边不只依赖五票。每段保留 rho、raw 支持数、signed 高差、MAD/分位差和 uncertainty；几何冲突的两族不能直接平均。重复 Raw section 结果可缓存，淘汰只重算，不改变门。

四个 phase 共用相同的分段原始点；高度剖面只统计实际查询行，连通域重复使用像元计数。这些计算优化保留相同的物理查询、统计值和支持门，不通过增大 voxel 或减少最终候选的 Raw 验证提速。旧 `centers()` 栅格调用契约继续兼容。

仅在候选 ROI 内建立 0.05 m 的四个确定性 phase：原点、半格 U、半格 V、半格 UV。比较 side rho 的 median/MAD/max deviation；不稳定提高不确定性，绝不整帧重复四次或以投票造舱。

相邻舱不能强制共用一个 U 站位。只有 Raw3D + BEV 的两条实测隔板面，才形成两个独立搜索边；随后分别精修。没有足够证据时保持未决，不按指定舱数或等宽补框。

任何明显向内移动都需多个独立占据 section 和一致的 Raw/BEV/Height 或合格 profile 支持。检查从原候选到最终边的总移动，包含隔板改站位；不足时 `KEEP_CONSERVATIVE_PREVIOUS_BOUNDARY`。逐边记录 inward move、支持比例、undercoverage risk 和 uncertainty。

最终四边重新求交，生成 `best_estimate_boundary_xy`；`review_coverage_boundary_xy` 表达保守复核范围。正交矩形只是显式模型约束，缺测边与推断角不能改名为 observed steel。角点带传播不确定性，钢边认证始终单列。

## 局部失败与诊断

一个开口组、一个舱或一条船的几何歧义只局部降级；继续兄弟对象。输入、配置、身份不一致、schema 损坏仍整帧失败。独立组使用 `independent_groups[]`、`aggregate_summary` 和各自来源，顶层没有唯一的 U 链/V 候选时为 null，不能复制第一组冒充全船。

`03_results.json` 同时包含 admission、拒绝原因、逐船/逐舱状态、逐边原始 section、角点、phase、undercoverage、阶段耗时与首次失败位置。选中证据保留；大量搜索/拒绝样本只截取 bounded samples，并记录总数、遗漏数和全量 digest。

## 强度辅助

先统计 finite、unique/effective unique、P5/P50/P95、MAD 与 robust range。缺失、全无效或近似常数时直接回退，不再执行第二次完整 B5；第二张图明确标记复用几何。

保留 `AUX_WEIGHT=0.05`，完整几何排序之后才允许强度末位 tie-break。船体参考轴不变，每舱局部轴独立，scorer 按轴缓存；后一舱不得继承前一舱的轴。强度只说明已有几何的辅助支持，不独立产生开口、改变钢边角色或绕过接受门。双雷达没有源身份时，`source_calibration=UNKNOWN`。

## 延续的技术结论与限制

局部甲板使用候选外围实测连续支持；Cargo、Wharf、空白和竞争平面不能靠 Global Deck fallback 成功。平面族保留 strict core、relaxed attachment 与空间角色；Cargo/Overflow 不能承担钢边确认票。密集的两侧回波可能是真实低舱—高甲板过渡，也可能是料脊，需 signed 高差和独立截面。

足迹内低舱回填不等于钢边；持久角点要求空间位置、L 形及象限支持，不能以高度层次数替代。复合 Proposal 的 lineage 允许 unmatched，不用匹配掩盖跨舱。首次全遮挡且无历史时保留 UNKNOWN/INSUFFICIENT_OBSERVATION。

旧 Normal6 数量为 2/1/1/1/1/3，只是开发召回参照。弱矩形、截图和已公开 Review A 不能作为钢内沿 Golden。08-01 隔板、08-08 弱边及 Cargo/Wharf 场景仍需独立物理内沿标注；真实泛化、自动目标船、跟踪联动和控制均未放行。历史过程结论由源码、测试与 Git 历史追溯，HEAD 不另建过程归档目录。

## 技术依据与使用边界

现有原语沿用局部邻域平面/法向估计、原始点高度断面和 Theil–Sen 稳健共识，四边精修统一调用这些原语。PCL 的[法向估计说明](https://pointclouds.org/documentation/tutorials/normal_estimation.html)说明邻域协方差及尺度选择；局部退化、稀疏或遮挡不能仅凭法向声明真实钢面。SciPy 的[Theil–Sen 文档](https://docs.scipy.org/doc/scipy-1.13.1/reference/generated/scipy.stats.theilslopes.html)提供稳健斜率估计，但斜率置信区间不能替代位置误差与传感器标定误差，因此仍记录 raw/MAD/相位偏差和保守 uncertainty。

SciPy 的[KD-tree 文档](https://docs.scipy.org/doc/scipy-1.13.1/reference/generated/scipy.spatial.cKDTree.query_ball_point.html)明确单点查询默认不排序。跨平台树遍历顺序不应进入有种子的拟合采样；本轮统一按物理 XYZ 排序后采样，并用邻域身份、反序与打乱反证验证。固定索引排序不能解决输入点序改变，物理坐标排序才是这里需要的确定性契约。

## 船舷与舱口内缘的角色核对

几何长线不能直接充当 opening inner edge。每个最终断面必须具有与该侧内法向一致的“内低外高”原始点证据；船舷外侧的反向下降即使有很多 profile 观测，也不计入 opening 支持。若旧 proposal 锚在船舷，只允许从既有 `support_search_m` 范围内的同船 Raw3D+BEV 实测模式重新提出边界；各模式继续使用原有 `boundary_search_m` 进行 Raw XYZ 定位，不放宽任何物理阈值。

替换要求至少原有 `profile_min_sections` 个独立物理断面、稳健线共识和同船双 provider 支持，记录 `opening_role_reanchor` 的候选来源、原始极性和断面数。多个竞争的物理模式继续 unresolved。总内移量仍相对于替换前边界计算；不确定性覆盖与最佳边界分离。相同物理查询的几何结果按完整证据键缓存，调用者保留独立 proposal 身份，缓存最多 64 MiB，淘汰只会重新计算。
