# AI 编码代理执行规范

> 状态：FROZEN
> 适用版本：V1.5-R / V1.5-T
> 最后更新：2026-09-22
> Owner：Ship-Unloader Engineering

适用于 Codex / ClaudeCLI / 其它自动编码代理。

## 1. 开工前

必须读取：

```text
README.md
CLAUDE.md
AGENTS.md
docs/00_项目总则与架构冻结.md
本阶段 Acceptance Contract
```

然后仅返回事实：

```text
BRANCH
BASE_SHA
HEAD_SHA
git status
IN_SCOPE
OUT_OF_SCOPE
STOP_CONDITION
```

没有完成以上步骤不得改代码。

## 2. 禁止自行决定

代理不得自行：

- 改架构；
- 改数据 split；
- 改 holdout；
- 改 acceptance threshold；
- 改 V1.4 frozen；
- 引入新深度学习架构；
- merge main；
- tag；
- force push；
- 读取 sealed annotation；
- 把失败门禁降级成 PASS。

## 3. 修改纪律

一项逻辑一个 commit：

```text
chore → docs → test → feature
```

不要混合。

每次修改必须能回答：

```text
为什么改
改了什么
如何验证
失败时如何回滚
```

## 4. 算法开发纪律

每次只修已经定位的 blocker。

例如：

```text
Oracle Local Geometry FAIL
→ 不允许先升级 CNN

Proposal miss
→ 不允许同时重写 tracking
```

禁止“大重构碰碰运气”。

## 5. 数据纪律

所有 raw / debug / report：

```text
Ship-Unloader-Data/
Ship-Unloader-Work/
```

Git 只保存：

```text
source
schema
small metadata
SHA
docs
tests
```

## 6. 失败纪律

失败必须保留，不能：

```text
删掉失败 case
调低门槛
把 unknown 改成功
用人工 GT 补 runtime
```

## 7. Push 前

必须执行：

```text
git status
git diff --check
git diff --cached --stat
tests
frozen gate
```

确认：

```text
no .pcd
no .ply
no .zip
no build
no validation artifact
no secret
```

## 8. 结束回执

```text
PREV_SHA=
NEW_SHA=
CHANGED_FILES=
COMMANDS=
TEST_RESULT=
REGRESSION_RESULT=
V1_4_FROZEN=
WORKTREE_CLEAN=
PUSH_STATUS=
NEXT_BLOCKER=
```

若 STOP CONDITION 到达，必须停止，不自主进入下一阶段。
